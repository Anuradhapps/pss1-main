# Pest Surveillance System (PSS) - User Guide

## 1. Purpose of This Document

This document is for all users of the Pest Surveillance System. It explains:

- what the project is;
- who uses it;
- how the system works;
- how to use each main feature;
- what to do in common situations.

This guide is written for both non-technical users and administrators.

---

## 2. What Is the Pest Surveillance System?

The Pest Surveillance System (PSS) is a web-based application used to manage agricultural pest surveillance work.

It helps the Department of Agriculture to:

- collect pest information from the field;
- store and organize the data safely;
- review reports and summaries;
- monitor trends over time;
- support decision-making for pest control and prevention.

In simple terms, the system replaces manual paper-based processes with a digital workflow.

## 4. How the System Works

The system is organized around a few main processes:

1. User login
2. Data entry or data review
3. Report generation
4. Dashboard and chart review
5. System administration and settings

Users work within their assigned role and only see the features relevant to their responsibility.

---

## 5. Getting Started

### 5.1 Login

To access the system:

1. Open the application in your web browser.
2. Go to the login page.
3. Enter your email and password.
4. Click login.

If you are a new user, your account must be created or approved by an administrator.

### 5.2 First Time After Login

After signing in, the system will usually open to your dashboard or home page.

From there you can:

- review your assigned tasks;
- open reports;
- enter or review data;
- manage users or settings if you are an administrator.

## 6. Main Features and How to Use Them

## 6.1 Dashboard

The dashboard is the main landing page for many users.

It may show:

- summary information;
- charts and statistics;
- recent data entries;
- important alerts or updates.

How to use it:

- review the overview before starting your work;
- look for updates or warnings;
- click related sections to open more details.

---

## 6.2 Data Collection

This is one of the most important parts of the system.

### For Collectors

Use this section when you need to record pest observations from the field.

Typical steps:

1. Open the collector or pest data section.
2. Select the relevant location or season.
3. Enter the pest information.
4. Add required observations such as counts or notes.
5. Save the record.

### Important notes

- Enter data carefully.
- Check for missing required fields before saving.
- Make sure the information matches the field observation.

---

## 6.3 Viewing and Editing Records

After data has been entered, users may need to review or update it.

How to use this:

- open the relevant record from the list;
- review the details;
- edit the information if needed;
- save the changes.

This is useful when:

- a field entry is incomplete;
- the previous record needs correction;
- more information becomes available later.

---

## 6.4 Reports and Exporting

The system includes reporting features for users to generate summaries and export files.

### What reports are used for

Reports help users:

- review collected data;
- analyse trends;
- share information with supervisors or management;
- prepare official records.

### Common report actions

- open a report from the reports section;
- filter by date, season, region, or other relevant criteria;
- generate a PDF or Excel file if available;
- download the file for sharing or printing.

### Best practice

Always verify the selected date range and filters before downloading a report.

## 10. Common Problems and What to Do

### Problem: I cannot log in

Possible causes:

- wrong password;
- inactive account;
- incorrect email.

What to do:

- check your username and password;
- contact the administrator if your account is not active.

### Problem: I cannot save a record

Possible causes:

- required fields are missing;
- invalid values were entered;
- the system is temporarily unavailable.

What to do:

- review the form carefully;
- fill in all required fields;
- try again;
- contact support if the issue continues.

### Problem: A report does not show the expected data

Possible causes:

- wrong date range;
- incorrect filter selection;
- missing records in the database.

What to do:

- check the selected filters;
- verify the date range;
- ask an administrator to review the data source.

### Problem: The page is not loading properly

What to do:

- refresh the browser;
- check your internet connection;
- try again later;
- report the issue if it continues.

## 11. Maintenance and Support

If you find a bug, broken feature, or unusual behavior:

1. Note what you were doing when the issue happened.
2. Capture the error message if one appears.
3. Report it to the system administrator or technical support team.

Good bug reports include:

- page or module name;
- your role;
- steps to reproduce the issue;
- screenshots or error text if available.
